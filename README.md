# 🌍 Земля 1942 — песочница истории

Мобильная браузерная игра-песочница: вы — бог-наблюдатель, который переписывает историю
Земли с **1942 года до наших дней**. Реальные границы и страны семи эпох, живая экономика,
войны, идеологии, ядерное оружие, стихийные бедствия и 41 инструмент вмешательства.

Сделана в духе **WorldBox** (god-sim песочница, нижняя панель инструментов, спавн и разрушение)
и **DroneFlames** (портретная мобильная стратегия: ФПВ-дроны, ракеты, авиация, флот, ПВО,
базы, артиллерийские удары), с экономикой, технологиями и дипломатией в духе **Hearts of Iron IV**.

Работает офлайн, без сборки и без зависимостей: один `index.html` + `style.css` + `js/`.

## Как запустить

### Вариант 1. GitHub Pages (телефон)

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**.
3. Откройте `https://<ваш-логин>.github.io/<репозиторий>/` с телефона.
4. «Поделиться → На экран «Домой»» — игра запустится как приложение (PWA-манифест и иконка уже есть).

### Вариант 2. Локально

```bash
# любой статический сервер
python3 -m http.server 8080
# или встроенный (без зависимостей)
node tools/serve.js      # http://localhost:8080
```

Открыть `http://localhost:8080`. Открывать `index.html` двойным щелчком тоже можно,
но браузер может заблокировать загрузку данных эпох (`file://`), поэтому сервер надёжнее.

## Что внутри

### Семь эпох, реальные границы

| Год | Название | Стран |
|-----|----------|-------|
| 1942 | Вторая мировая (базис 1938: Ось, Аншлюс, оккупации) | 158 |
| 1945 | Послевоенный мир | 171 |
| 1960 | Деколонизация | 156 |
| 1994 | Новый порядок | 192 |
| 2000 | Миллениум | 192 |
| 2010 | Современность | 192 |
| 2024 | Наши дни | 239 |

Для каждой страны заданы население, ВВП и ВВП на душу, армия, технологии, стабильность,
идеология (демократия, авторитаризм, коммунизм, фашизм, монархия, исламизм, хунта),
блок (Ось, Коалиция, НАТО, ОВД, ОДКБ, ЕС, БРИКС, нейтралитет), ядерный арсенал,
вассалитет и колониальная зависимость.

### Время

Скорости **❚❚ (пауза), ×1, ×2, ×5, ×10, ×20** — от спокойного наблюдения до быстрой перемотки
десятилетий. Один игровой день = один тик экономики; 365 дней = год.

### 41 инструмент в 5 вкладках

- **Государство** — осмотр, идеология, стабильность, экономика, армия, дипломатия, территория
  (аннексия, вассалитет, отделение, раздача независимости).
- **Армия** — пехота, танки, артиллерия, **ФПВ-дрон**, авиация, флот, ПВО, ядерный заряд, база.
  Юниты двигаются, воюют и умирают по своим правилам.
- **Разрушение** — взрыв, артобстрел, авиаудар, ракета, **ядерный удар**, метеорит,
  землетрясение, цунами, чума, пожар, торнадо.
- **Созидание** — город, крепость, завод, очистка заражения, процветание.
- **Мир** — мир во всём мире, ядерный апокалипсис, пандемия, золотой век, сброс мира.

### Живая симуляция

- рост населения и ВВП по типам стран, технологии, стабильность, восстания и смены строя;
- ИИ объявляет войны, воюет блоками, заключает мир по истощению, аннексирует и создаёт вассалов;
- ядерные программы появляются у развитых стран, ИИ применяет ядерное оружие;
- случайные события: революции, эпидемии, землетрясения, наводнения, забастовки, реформы,
  технологические прорывы, коррупционные скандалы, месторождения нефти;
- история мира — лента событий с датами (кнопка ≡) и бегущая строка сверху.

### Карта и интерфейс

- 11 режимов карты: политический, идеологии, блоки, мощь, экономика, армия, технологии,
  стабильность, ядерный арсенал, вассалитет, климат.
- Мини-карта с переходом по тапу, зум 2.6×, плавное перемещение, подписи стран,
  автоматическое скрытие мелких подписей при отдалении.
- Портретный мобильный интерфейс: нижняя панель как в WorldBox, карточка страны
  над панелью, безопасные отступы (вырез/жесты), поддержка тач- и мышиного управления.
- Сохранение в 3 слота + автосохранение, экспорт/импорт мира в JSON, настройки.

## Управление

| Действие | Жест |
|---|---|
| Выбрать инструмент | тап по кнопке в нижней панели |
| Применить | тап по карте (инструменты разрушения/созидания применяются по удержанию) |
| Открыть страну | инструмент «Осмотр» → тап по стране |
| Двигать карту | перетаскивание одним пальцем |
| Зум | щипок двумя пальцами / колесо мыши |
| Центрировать | ◎ |
| История | ≡ |
| Режим карты | ◧ |
| Меню (сохранение, настройки, помощь) | ☰ |

## Структура проекта

```
index.html            разметка и порядок подключения скриптов
style.css             вся вёрстка (мобильный first, тёмная тема)
manifest.webmanifest  PWA-манифест
icon.svg              иконка
js/core.js            утилиты (U), глобальное состояние (App), шина событий
js/fx.js              эффекты: взрывы, дым, ракеты, трассеры, зоны, тряска
js/render.js          canvas: проекция, камера, отрисовка карты, подписи, мини-карта
js/world.js           страны, войны, аннексии, соседство, сохранение/загрузка
js/sim.js             дни, экономика, войны, ИИ, катастрофы, смена эпох
js/units.js           движение и бой юнитов
js/tools.js           инструменты бога, иконки, применение
js/audio.js           процедурный звук (WebAudio, без файлов)
js/ui.js              интерфейс: панели, карточка страны, модальные окна
js/main.js            запуск, ввод, цикл кадров, динамическая загрузка эпох
js/data/              данные: 7 эпох, 255 стран, политика
tools/                инструменты разработки (см. ниже)
```

## Инструменты разработки

```bash
node tools/smoke.js          # быстрый дымовой тест движка (эмуляция DOM/canvas)
node tools/ui-test.js        # интеграционный тест интерфейса в jsdom
node tools/evo-test.js 30    # прогон 30 лет симуляции со статистикой
node tools/preview.js 420 820 0.095 1700 -5050 /tmp/eu.png   # статичный предпросмотр карты
node tools/build-data.js     # пересборка данных эпох из исходников
```

Для `ui-test.js`, `preview.js` и `build-data.js` нужны пакеты:
`cd tools && npm i` (jsdom, sharp).

## Источники данных и лицензии

- **Границы:** [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps)
  (GPL-3.0) для 1945–2010, [datasets/geo-countries](https://github.com/datasets/geo-countries)
  (PDDL) для 2024; снимок 1938 года использован как база 1942 года.
- **Население и площади:** [samayo/country-json](https://github.com/samayo/country-json) (MIT).
- **Экономика, армии, идеологии, блоки:** авторская модель, откалиброванная по историческим
  порядкам величин; значения округлены и не претендуют на научную точность.
- **Код, интерфейс, звук:** написаны с нуля; внешние ассеты не используются.

Игра не является исторической реконструкцией и не содержит политических оценок:
это песочница, где игрок сам решает, как сложится история.
